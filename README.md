# Информационная система инвестиционной компании

Desktop-приложение на Kotlin/JVM и Compose Desktop для учета клиентов, инвестиционных счетов, финансовых инструментов, сделок, портфелей и дивидендов.

## Возможности

- вход путем выбора одного из нескольких сотрудников без пароля;
- отображение выбранного пользователя и его роли;
- обзор основных показателей компании;
- создание, изменение и архивирование сотрудников и клиентов;
- создание, изменение и безопасное закрытие инвестиционных счетов;
- создание, изменение и архивирование финансовых инструментов;
- добавление и удаление последних цен инструментов;
- создание, изменение и удаление покупок и продаж;
- проверка доступного количества при продаже;
- динамическая фильтрация сделок по типу, периоду и сумме;
- расчет состава, стоимости и результата портфелей;
- создание, изменение и удаление дивидендных начислений;
- отчеты по месячному обороту и структуре активов;
- автоматическое заполнение демонстрационными данными при первом запуске.

Сущности, участвующие в финансовой истории, не удаляются каскадно: сотрудники, клиенты и инструменты архивируются, а счета закрываются. Сделки и начисления допускают физическое удаление с подтверждением, после чего отчеты и портфели пересчитываются.

## Технологии

- Kotlin 2.4.0 и Java 21;
- Compose Multiplatform Desktop и Material 3;
- SQLite и SQLDelight 2.1.0;
- Kotlin Test, JUnit 5 и Konsist;
- Gradle Kotlin DSL.

## Запуск

```bash
./gradlew run
```

При первом запуске приложение создает базу данных и демонстрационные данные. Файл базы находится по адресу:

```text
~/.investcompany/invest-company.db
```

## Проверка

```bash
./gradlew test
./gradlew build
```

Тесты используют отдельную реальную SQLite в памяти и не изменяют пользовательскую базу данных.

## Сборка desktop-дистрибутива

```bash
./gradlew createDistributable
```

Результат для текущей ОС:

```text
build/compose/binaries/main/app
```

DMG на macOS:

```bash
./gradlew packageDmg
```

MSI необходимо собирать на Windows:

```text
gradlew.bat packageMsi
```

Compose Desktop формирует нативный установщик только для текущей операционной системы.

## Соответствие требованиям курсового проекта

SQLDelight-схема находится в:

```text
src/main/sqldelight/me/investcompany/persistence/db/Investment.sq
```

В ней реализованы:

1. выборка клиентов, счетов, инструментов и сделок;
2. регистронезависимый поиск клиентов;
3. группировка стоимости портфелей по клиентам;
4. добавление сущностей;
5. изменение статусов и справочных данных;
6. удаление сделок и дивидендов;
7. динамический запрос сделок с необязательными параметрами;
8. индексы для имен клиентов, связей, дат и инструментов;
9. ограничения `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK` и `NOT NULL`.

Подробный план курсового проекта и список материалов для пояснительной записки находятся в [PROJECT_PLAN.md](PROJECT_PLAN.md).

## Основной сценарий работы

1. Откройте раздел «Клиенты» и создайте клиента.
2. Откройте ему счет в разделе «Счета».
3. Создайте инструмент или выберите демонстрационный.
4. Зарегистрируйте покупку в разделе «Сделки».
5. Проверьте рассчитанную позицию в разделе «Портфели».
6. Добавьте новую цену инструмента и посмотрите изменение стоимости.
7. Используйте фильтры сделок для демонстрации динамического SQL-запроса.
8. Откройте раздел «Отчеты» для просмотра группированных результатов.
