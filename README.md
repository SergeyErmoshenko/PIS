# Информационная система предприятия автосервиса

Desktop-приложение на Kotlin/JVM и Compose Desktop для учета сотрудников, клиентов, автомобилей клиентов, услуг, запчастей, заказ-нарядов и платежей автосервиса.

## Возможности

- вход путем выбора одного из нескольких сотрудников без пароля;
- отображение выбранного пользователя и его роли;
- обзор основных показателей автосервиса;
- создание, изменение и архивирование сотрудников и клиентов;
- создание, изменение и безопасное списание автомобилей клиентов;
- создание, изменение и архивирование услуг и запчастей;
- добавление и удаление последних цен услуг;
- создание, изменение и удаление заказ-нарядов;
- проверка активного состояния автомобиля при открытии заказ-наряда;
- динамическая фильтрация заказ-нарядов по автомобилю, клиенту, услуге, статусу, периоду и сумме;
- расчет расхода запчастей и платежей по заказ-нарядам;
- создание, изменение и удаление расходов запчастей и платежей;
- отчеты по месячному обороту и выручке по категориям услуг;
- автоматическое заполнение демонстрационными данными при первом запуске.

Сущности, участвующие в истории обслуживания, не удаляются каскадно: сотрудники, клиенты, услуги и запчасти архивируются, а автомобили списываются. Заказ-наряды без зависимых расходов и платежей допускают физическое удаление с подтверждением, после чего отчеты пересчитываются.

## Технологии

- Kotlin 2.4.0 и Java 21;
- Compose Multiplatform Desktop и Material 3;
- SQLite и SQLDelight 2.1.0;
- Kotlin Test, JUnit 5 и Konsist;
- Gradle Kotlin DSL.

## Запуск

```bash
./gradlew run
```

При первом запуске приложение создает базу данных и демонстрационные данные. Файл базы находится по адресу:

```text
~/.autoservice/auto-service.db
```

## Проверка

```bash
./gradlew test
./gradlew build
```

Тесты используют отдельную реальную SQLite в памяти и не изменяют пользовательскую базу данных.

## Сборка desktop-дистрибутива

```bash
./gradlew createDistributable
```

Результат для текущей ОС:

```text
build/compose/binaries/main/app
```

DMG на macOS:

```bash
./gradlew packageDmg
```

MSI необходимо собирать на Windows:

```text
gradlew.bat packageMsi
```

Compose Desktop формирует нативный установщик только для текущей операционной системы.

## Соответствие требованиям курсового проекта

SQLDelight-схема находится в:

```text
src/main/sqldelight/me/autoservice/persistence/db/AutoService.sq
```

В ней реализованы:

1. выборка сотрудников, клиентов, автомобилей и заказ-нарядов;
2. регистронезависимый поиск клиентов;
3. группировка расходов клиентов по автомобилям;
4. добавление сущностей;
5. изменение статусов и справочных данных;
6. удаление заказ-нарядов, расходов запчастей и платежей;
7. динамический запрос заказ-нарядов с необязательными параметрами;
8. индексы для имен клиентов, связей, дат и услуг;
9. ограничения `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK` и `NOT NULL`.

Подробный план курсового проекта и список материалов для пояснительной записки находятся в [PROJECT_PLAN.md](PROJECT_PLAN.md).

## Основной сценарий работы

1. Откройте раздел «Клиенты» и создайте клиента.
2. Добавьте ему автомобиль в разделе «Автомобили».
3. Создайте услугу или выберите демонстрационную.
4. Зарегистрируйте заказ-наряд в разделе «Заказ-наряды».
5. Добавьте расход запчасти в разделе «Расход запчастей».
6. Зарегистрируйте платеж по заказ-наряду в разделе «Платежи».
7. Используйте фильтры заказ-нарядов для демонстрации динамического SQL-запроса.
8. Откройте раздел «Отчеты» для просмотра группированных результатов.
